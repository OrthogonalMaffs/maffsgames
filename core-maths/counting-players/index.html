Counting Players: a Core Maths practice paper built on real website data

For teachers: Counting Players is a free Level 3 Core Maths practice pack with preliminary material, a data file, a 90-minute practice paper of 56 marks and a mark scheme. It is written in the style of Level 3 Core Maths examinations; it is not an exam board paper and is not endorsed by any exam board. The data is MaffsGames' own site statistics, anonymised. This is a first edition, shared for feedback.
