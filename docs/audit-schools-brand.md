## What stopped the edit, and Jon's rulings

The contract's STOP IF fired before step 2. Jon ruled on 28 September 2026, and the edit went ahead on those rulings:

1. **A BRAND hit in `games/`** — one: `games/complex-converter/index.html:181`, whose back link read `← Schools`. No other game carries the brand; every other `games/` occurrence is a path or question content. *Ruling: change it to `← Back to Games`, the label 69 other games use.*
2. **Variants other than "MaffsGames Schools"** — three: that link; "The schools portal grew out of an earlier project" at `about/index.html:179`; and `<!-- Schools Portal -->` at `sitemap.xml:7`, a comment never displayed, in a DO NOT TOUCH file. *Rulings: the About line becomes "This site grew out of an earlier project"; the sitemap comment stays.*
3. **A hit that could not be classified with confidence** — `about/index.html:179`, ruled above.
4. **The word is baked into a raster** — `schools/assets/og-image.png` reads "Free maths games for schools" under the wordmark. That is CONTENT, not the brand: the image already says just **MaffsGames**. Its source, `schools/assets/og-image.svg:17`, carries the same line. *Ruling: leave both.* The other rasters are the escape-room art in `docs/art/`; the house rule is that any lettering in a scene is transcribed into its `alt`, and no `alt` in `escape-rooms/` contains the word.

`schools/assets/m_plus_logo.svg` contains no text at all, so contract step 3 had nothing to do. The portal header was a plain text node, `MaffsGames Schools`, inside the `<h1>`; there was no separate "Schools" element and so no CSS that existed only to style it.

"for UK schools" in the portal's titles, descriptions, JSON-LD and header subtitle is CONTENT and stays, by Jon's ruling. The audience question it raises is a separate decision.

## Found along the way — not fixed

Each needs its own contract.

1. **complex-converter has no Aa toggle** (above). It is the only game of the 95 with the Aa CSS and no switch; the four others without the `mfg_accessible` key (shape-shifter, probability-pioneer, like-terms-collector, truth-will-set-you-free), and boolean-blitz with its differently named class, all have a working button and script.
2. **The OpenDyslexic font URL may not exist.** 92 games load the Aa font from `https://cdn.jsdelivr.net/npm/opendyslexic@latest/fonts/…`. jsDelivr's `/npm/` path serves npm packages, and the npm registry has no package called `opendyslexic` (checked 28 Sep 2026, with `katex` answering normally as a control; the nearest names are `@fontsource/opendyslexic` and `open-dyslexic-cdn`). If that URL 404s, Aa mode on those games has been showing a generic sans-serif. Not observed directly, because jsDelivr is blocked from the session that found it; opening the URL in a browser settles it.
3. **The portal uses an emoji as decoration**: `&#127942; Leaderboards` at `index.html:659`, against the brief's "no emoji as decoration". Jon: noted, out of scope.
4. **Spec Map scrolls sideways on a phone**: at a 380px viewport the page is 435px wide, before and after this change. Jon: noted separately.
