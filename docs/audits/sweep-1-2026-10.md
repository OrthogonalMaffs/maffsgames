# SWEEP-1: the reading sweep (October 2026)

Canon §0.2, exit-bar point 6: one reading sweep of every live game for true wrong options (SR-16, SR-24), unstated
conventions (SR-1, SR-17), words against figure (SR-6, SR-25) and SR-14 content. Contract
`docs/handover/contracts/2026-10-12-sweep-1.md` (cloud lane). 96 games, glorious-gantt skipped (Jon, 12 Oct), in
order of lowest level served, about 8 a batch. Each game's findings are in `docs/audits/findings/<slug>.yml` with
ids `<slug>-s1-NNN`; this file is the summary. Classes used: `NEW:true-wrong-option`, `NEW:convention-unstated`,
`NEW:precision-not-stated`, `NEW:text-contradicts-content`, `NEW:sr14-content`.

**Method.** Each game read as served: the bank as the live page held it (`extract-banks.py`, run offline as
`docs/sandbox-checks.md` describes), or for a generated game its templates and draws; the page's stems, options,
keys, hints, worked steps and feedback; the verifier read first, so what it already recomputes is not re-checked.
Every candidate was checked against the page before it was recorded.
