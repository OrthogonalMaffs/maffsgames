# Answer-key audit, tranche 3 (6 Oct 2026)

Read-only audit of nine games on `main` at `4be3342`: factor-race, like-terms-collector,
four-quadrant-explorer, formula-plug-in, new-shapes, shape-shifter, prime-factorisation,
constructions-lab, truth-buster. Nothing in the repo was changed by the audit; this file and
`docs/audits/findings/tranche-3.yml` are its delivery (Jon, 6 Oct 20:20).

Method: every key recomputed (Python Fraction or SymPy; generators enumerated in the page);
every game played in Chromium against a stubbed local server at 390×844 and other sizes. Every
CRITICAL and HIGH was re-read at its source line, and the double finish (both games), Like Terms
Collector's decimal entry and Four Quadrant Explorer's double-click Start were reproduced a second
time. `submitScore` calls were recorded and never sent; Firebase never loaded. **Personal data or
security:** nothing found in any of the nine games.

## 2. CRITICAL and HIGH

1. **like-terms-collector:416 — CRITICAL, JC, class 7.**
   - The code is `parseInt(i.value,10)` compared with `===` against the key.
   - Item 1 (`3🍎+5🍎+2🍊+4🍊`, key [8, 6]): typing 8.9 and 6.5 gives parseInt values 8 and 6, and the
     answer is marked ✓.
   - The input is `type=number`, so the decimal is accepted. Reproduced twice.
   - All 15 Stage 1–2 items behave the same, so a whole run can end 45/45 with wrong answers.
2. **like-terms-collector:187, :195 — HIGH, JC, class 1.**
   - A double-click on Continue or Keep going sends the second click to the Stage 3 option now under
     the pointer.
   - Q16, Q26 and Q36 arrive already answered, wrong in the runs.
   - Reproduced at 390 and 1280.
3. **four-quadrant-explorer:156, :191, :484 — HIGH, JC, class 1.**
   - A double-click on Start or Play Again lands on the canvas, and Q1 (Plot It) is marked wrong.
   - Reproduced at 1280×800: `question_answered` index 1 with `correct:false`.
4. **formula-plug-in:611 — HIGH, NEW:double-finish.**
   - The reveal screen's 8-second `setTimeout(showResults)` is never cleared after the student taps
     through at 5 seconds or later.
   - Reproduced: 2× `game_completed` and 2× `submitScore(...,7,20)`.
   - If the student taps, presses Play Again and starts within 3 seconds, the stale timer ends the
     new game and submits 0.
5. **new-shapes:924–928 — HIGH, NEW:double-finish.** The same template and the same code.
   Reproduced the same way, with two submits.
6. **truth-buster:268 (tb_t2_018) — HIGH, class 3.**
   - The statement "π contains every possible finite sequence of digits" is keyed false. Its truth
     is unknown, and the item's own reveal title says "We don't know".
   - This is the "unproven is not false" fault already fixed for Goldbach in `e153859`.
   - The text also says nobody has proved that 123456789 appears, then gives its position. It also
     misdefines normality.
7. **truth-buster:274, :275, :285 (tb_t3_001, t3_002, t3_012) — HIGH, JC, class 2.**
   - "The angles of a triangle always add up to 180°", "Parallel lines never meet" and "√−1 doesn't
     exist" are keyed false.
   - Each key holds only after silently leaving the Euclidean plane or the reals.
   - Meanwhile tb_t1_008 (:235) is keyed by assuming the flat plane, and one session can deal both
     kinds.
   - Under either convention the mismarked items are under 10%, so this is not CRITICAL.
8. **truth-buster:277 (tb_t3_004) — HIGH, JC, class 2.** Sphere eversion is keyed true, but the
   statement leaves out "allowed to pass through itself". Only the reveal states that condition, and
   the result needs it.

## 5. Rulings needed from Jon

1. **Does a decimal answer to a counting item count towards CRITICAL?** Recommendation: yes, keeping
   Like Terms Collector at CRITICAL. The definition counts items, not how likely the input is, and
   the fix is one call to `MaffsAnswer.exact`.
2. **Board-mixing severity.** Recommendation: MEDIUM throughout, with the three games added to canon
   §9's list. The fix is the modes contract, not each game in turn. Holding the boards meanwhile, as
   `distinctly-average` does, is Jon's call.
3. **Truth Buster's tier-3 convention items.** Recommendation: reword each statement so its key holds
   as written, as Goldbach was:
   - "On every surface, a triangle's angles add up to 180°"
   - "In every geometry, parallel lines never meet"
   - "√−1 doesn't exist in any number system"
   - "…if it may pass through itself" for the sphere
   - "It has been proved that π contains…" for π
4. **Class 1 transition clicks.** Recommendation: contract F fixes this once in shared code: ignore
   input for the first few hundred milliseconds of a new screen. Patching each Continue button would
   leave the next game exposed.
5. **Constructions Lab.** The choice is between adding a construction checker and declaring it a
   learning tool, exempt from the marking bar. Recommendation: the exemption, with the snapping fix
   and the task 6 and 9 text fixes still done.
6. **Shape Shifter's 180° items.** Restoring them needs a different "wrong direction" distractor, for
   example a 90° turn. That is a content call for Project Claude to draft.
7. **Board keys.**
   - Prime Sprint: recommendation, the hub lists `[year6, all]`.
   - Factor Race: recommendation, drop GCSE from the roster, portal and hub until GCSE content exists.
   - Either way, `check-leaderboard-coverage.js` should resolve variable levels.
