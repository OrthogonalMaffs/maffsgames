EXACT CHANGE:
Premise (the name): the denominator says how many parts; only parts of the same size can be added or subtracted. Every bar-model message says so in those words or close to them.
Stages: (a) add/subtract, same denominator; (b) add/subtract, one denominator a multiple of the other; (c) add/subtract, unrelated denominators; (d) multiply, fraction x whole then fraction x fraction; (e) divide, framed first as "how many quarters in 3?"; (f) mixed numbers, all four operations. No fraction of an amount (Free Daily Pizza's).
Levels (Jon, 20 Oct; MaffsLevel.resolve): key ks3, label "Foundation", stages (a)-(d); key gcse, label "Advanced", stages (a)-(f). Roster levels KS3, GCSE. Each level has its own board (SR-22). Session: Foundation 20 (5 per stage), Advanced 24 (4 per stage), stages in order.
Answers: (a)-(c) multiple choice, four options (SR-4), every distractor a named error, none equal in value to the key (so no unsimplified equivalent of the key ever appears as an option). Required named errors where they apply: adding tops and adding bottoms; adding the numerators and keeping the larger denominator; changing a denominator without its numerator; multiplying the denominators but adding the numerators. (d)-(f) typed on MaffsKeypad (numerator and denominator boxes; whole, numerator and denominator for mixed answers), marked ONLY through FRACTION-FORM's shared function. Simplest form (Jon, 20 Oct): an equal but unsimplified answer gets the format message, neither right nor wrong (SR-3). Valid alternative methods are never errors: dividing across in (e) when it divides exactly; adding wholes and parts separately for mixed-number addition. Mixed-number multiplication by multiplying wholes and parts separately IS an error.
Bar model (Jon, 20 Oct): drawn on the first 3 questions of every stage; after any wrong answer, drawn in the feedback on the question's own numbers, and again on the next question. Area model for fraction x fraction.
Misconception feedback: the first three times per session a student commits a named error, a worked example on the question's own numbers that waits for Next; after that, a one-line nudge (as Just Pythag It, Bruv). Correct answers advance briskly.
Generation: every question from finite pools built once (no redraw loop, canon §12, SR-5); every stage's pool at least 40 distinct questions per level that serves it; a filter pass at build removes any question where a named error, rounded as the key is, equals the key (as #453).
Platform: light theme (lowest tier KS3, canon §7.5.1); no calculator; visible count-up, scored, never times a student out; MaffsLock with its hint declaration (canon §7.6.0); standard header, KaTeX for every fraction shown; GA4 and Sheets events as every game (mode = stage); leaderboard per level.
