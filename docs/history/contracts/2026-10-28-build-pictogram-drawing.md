# Contract: PICTOGRAM-DRAWING (Jon, 28 Oct 2026; build lane; saved verbatim)

TASK: Make pictograms in the reading-charts bank draw half and quarter symbols, and make CI check that every generated chart's drawing matches its data.
ROOT CAUSE: In schools/assets/reading-charts-generator.js the pictogram renderer draws only whole symbols, so partial symbols in the data are dropped from the SVG. Seen live: As You Can See, Stage 1 Q1, school lunches, Thursday — data and worked answer say 1 whole + 1 half = 9; the drawing shows 1 whole symbol. The content verifier passed because it checks answers against data, never against what is drawn.
CLASS CHECK: Yes, on two counts. (1) The renderer is shared infrastructure: every pictogram item with a half or quarter in the bank is wrong, in every game that imports it. Fix the renderer, not individual items. (2) The verifier gap is shared across all chart banks (reading-charts, pie-chart, probability where drawn): a drawing that disagrees with its data passes CI. Add a drawing-versus-data check at the verifier layer, applied to every chart type the banks generate, not just pictograms.
EXACT CHANGE: (a) reading-charts-generator.js: pictogram renderer draws whole, half and quarter symbols exactly as the item's data specifies; partial symbols visibly cut (e.g. clipped diamond), consistent with the key. (b) Same file: fix the worked-step text so counts agree in number ("1 whole symbol", "2 whole symbols"), and fix the key text so it reads "◆ = 6 lunches" (no "Key: =" stray). (c) Verifier: for each generated chart item, parse the rendered SVG back to values (symbol counts incl. fractions; bar heights; pie angles; plotted points) and assert they equal the item's data. Run across every chart-generating bank. Report any other items that fail.
DO NOT TOUCH: Question wording, answers or slip logic beyond (b); game page layouts; the pie-chart and probability banks' content (verifier coverage only); listing state of any game.
SUCCESS CONDITION: Every pictogram item renders symbols matching its data, checked by the new verifier; the new check runs in CI for all chart banks and passes; a list of any other mismatched items found is in the handover; As You Can See Stage 1 Q1 shows 1 whole + 1 half for Thursday on the live site; work committed and handover recorded in CLAUDE.md.
STOP IF: the verifier finds mismatches in any bank other than reading-charts (report, don't fix); parsing SVG back to values isn't reliable for a chart type (propose an alternative, e.g. renderer emitting data attributes, before building); the fix needs changes to MaffsAnswer or any shared file outside the banks and verifier.
