How to Use the Tools

🔵 Compass Tool
1. Click a centre point on the canvas
2. Click a second point to set the radius
3. An arc is drawn centred on the first point, passing through the second
4. The arc draws a full circle — use this to find intersection points
🟠 Ruler Tool
1. Click a start point
2. Click an end point
3. A straight line is drawn between them
4. Use intersection points from your compass arcs as start/end points
⚫ Point Tool
1. Click anywhere to place a point
2. Use this to mark intersection points where arcs cross
3. Points snap to nearby intersections automatically
🔒 Lock Radius
1. Draw a compass arc with the radius you want
2. Click the Lock Radius button in the toolbar
3. Now each click places a new arc at that exact radius — no need to set it again
4. Essential for perpendicular bisectors and angle bisectors where both arcs must be equal
5. Click again to unlock and set a new radius
Tips
• Set your compass radius to more than half the line segment
• Draw arcs from both ends to find the perpendicular bisector
• The intersection of two arcs gives you a construction point
• Use Lock Radius when you need equal arcs from different centres
• Use ↩ Undo if you make a mistake
