How Many Parts?

Adding and taking away fractions.
Foundation Non-calculator

The denominator, the bottom number, says how many parts the whole is cut into: 3/4 is 3 parts of a whole cut into 4.

Only parts of the same size can be added or taken away. When the bottoms are different, cut both into the same number of parts first.

Level

Stages, in order

  • 1Same bottom number: the parts are already the same size.
  • 2One bottom number is a multiple of the other.
  • 3Different bottom numbers: find a number of parts both fit.
